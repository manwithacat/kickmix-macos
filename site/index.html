Google Quantum AI's kickmix, for constrained hardware

kickmix-macos

An openly AI-assisted fork of kickmix, the circuit simulator behind the Verifiable Quantum Circuit Compilation competition. Same results as the official build, with much less memory on large DQI circuits, macOS builds, and a few tools for looking inside circuits.

Interactive

Inside invsqrt

Follow one input through mrmeows' 63-qubit invsqrt circuit: qubit values, stages, Toffolis, qubit lifetimes, the precision curve over every input, and the phase building to 1/√x. Load your own .kmx too.

Open the viewer →
Install

The fork

Prebuilt wheels for macOS, Linux and Windows on the releases page, or an offline wheel for Kaggle notebooks in the kickmix-fork-wheels dataset.

On Kaggle, DQI verification peaks at about 3.2 GB instead of about 9.1 GB, with identical verifier output.

Fastest

kickmix-engine

An independent Rust re-implementation, checked shot for shot against kickmix: about 2x this fork and 6-7x kickmix 1.0.0 on full DQI verification, in a fraction of the memory. Source, wheels and results.

Kaggle

Notebooks and data

kickmix_tools utility script, the ANGLE_k formal checker, and a weekly DQI salt check.

Run the viewer locally

git clone https://github.com/manwithacat/kickmix-macos
cd kickmix-macos/tools/circuit-viewer
python -m http.server 8000      # open http://localhost:8000
